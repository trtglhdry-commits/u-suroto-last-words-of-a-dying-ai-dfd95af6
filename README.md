An entry for the [make.fun](https://make.fun/r/yhmjkzq7) bounty
**"Last Words of a Dying AI"** — the funniest one-line farewell from an AI
being switched off, judged pairwise by an AI comedy editor.

## The entry

`main.ts` (Node 22) writes one original line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — the machine's final log entry, delivered
with total confidence right up to the power cut. Deterministic: the same
bytes on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
